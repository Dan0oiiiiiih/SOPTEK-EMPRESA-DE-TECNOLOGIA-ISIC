# SOPTEK — GitHub Pages

Esta carpeta contiene el sitio listo para publicar.

## Archivos
- `index.html`: página principal.
- `soptek-logo.jpg`: logotipo utilizado en el sitio.

## Publicar
1. Crea un repositorio en GitHub llamado `soptek` (o el nombre que prefieras).
2. Sube `index.html` y `soptek-logo.jpg` a la raíz del repositorio.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.

La dirección tendrá este formato: `https://TU-USUARIO.github.io/soptek/`.
